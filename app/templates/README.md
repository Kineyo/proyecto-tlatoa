# Plantillas Jinja2 (Backend FastAPI)

> ⚠️ **Atención**: Los archivos en esta carpeta son **plantillas del motor Jinja2** para el servidor web de FastAPI (`app/main.py`), por lo que contienen etiquetas de extensión (`{% extends %}`, `{% block %}`, `{{ app_name }}`).

Si deseas **abrir y ver la web directamente en tu navegador sin tener Python instalado ni correr ningún servidor**, tienes dos opciones inmediatas:

1. **Doble clic en `web/index.html`**:
   Abre directamente la interfaz en cualquier navegador (`file://`) 100% pre-renderizada y funcional con buscador interactivo y cero dependencias.
2. **Doble clic en `./bin/tlatoa-desktop` o `./iniciar_tlatoa.sh`**:
   Lanza la aplicación nativa en Rust que consulta la base de datos completa de 16,100 registros con latencia `< 1ms` y abre tu navegador automáticamente.
