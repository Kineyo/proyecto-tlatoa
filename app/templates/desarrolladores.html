¿Cómo compilar y ejecutar según tu OS?

Despliega tu sistema operativo para ver los comandos de terminal y la sublista Agentes.

Comandos de instalación, ejecución y verificación (Bash / Zsh): 
# 1. Copiar configuración de entorno
cp .env.example .env

# 2. Crear entorno virtual e instalar dependencias
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Iniciar servidor FastAPI con recarga en vivo
uvicorn app.main:app --reload --port 8000

# 4. Validar sintaxis Python y chequeo de salud CLI
python3 -m py_compile app/main.py app/routers/web.py
php tools/gateway.php health

Pega este prompt al inicio de tu conversación con Cursor, Claude, ChatGPT, Gemini o Copilot: 
Estás trabajando en Proyecto Tlatoa sobre Linux (entorno POSIX con rutas `/`).
REGLAS OBLIGATORIAS DE RUTAS Y ENTORNOS:
1. El servidor activo corre en Python / FastAPI en `app/main.py` sirviendo plantillas Jinja2 desde `app/templates/`.
2. Todo desarrollo nuevo de backend, endpoints y vistas DEBE implementarse en `app/routers/`, `app/services/` y `app/templates/` (NO en `src/` ni `views/` salvo herramientas CLI).
3. Los datasets JSON viven en `storage/data/json/`.
4. Para verificar sintaxis y estado en terminal usa:
   - `python3 -m py_compile app/main.py app/routers/web.py`
   - `php tools/gateway.php lint "src/Services/MiArchivo.php"`
   - `php tools/gateway.php health`
   - `php tools/gateway.php git:status`
5. Mantén neutralidad estricta, archivos < 400 líneas, enlaza siempre `fuente_url` oficial (.gob.mx) y nunca uses `git add .`.

Comandos de instalación, ejecución y runner centralizado (PowerShell): 
# 1. Copiar configuración de entorno
Copy-Item .env.example .env

# 2. Crear entorno virtual e instalar dependencias
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3. Iniciar servidor FastAPI con recarga en vivo
uvicorn app.main:app --reload --port 8000

# 4. Validar sintaxis y salud mediante el runner centralizado de Windows
python -m py_compile app\main.py app\routers\web.py
powershell -ExecutionPolicy Bypass -File .\tools\run.ps1 health
